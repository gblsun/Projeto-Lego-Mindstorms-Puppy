# Projeto LEGO Mindstorms - Puppy

Projeto da disciplina envolvendo o robô EV3 Puppy do LEGO MINDSTORMS, programado em Python (Pybricks).

## Estrutura do repositório

- [`puppy/`](puppy/) — código-fonte do programa do robô ([`main.py`](puppy/main.py)) e configurações do VS Code.
- [`Materiais de Aula/`](Materiais%20de%20Aula/) — PDFs, DOCX e PPTX fornecidos na disciplina (roteiro de avaliação, instruções de configuração do ambiente, manual do usuário do EV3, template de apresentação, etc.).

## Executando

O programa em `puppy/main.py` requer o LEGO EV3 MicroPython v2.0 (Pybricks). Instruções de montagem e instalação do firmware estão nos materiais de aula, em especial em "Configurando o Ambiente.pdf" e "Importante Micro SD.docx".
